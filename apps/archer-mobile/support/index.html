ARCHER Mobile — Support

Last updated: 13 October 2026 · English

ARCHER Mobile 1.0.0 is an experimental iOS/iPadOS audio processor. It is not yet available as a public iOS App Store release.

What the development build contains

  • Actual clipping/audio-processing code in a standalone iOS app.
  • An Audio Unit v3 effect extension for compatible audio hosts.
  • Touch-focused Gain, Threshold and Atmosphere controls.
  • Optional microphone input, subject to system permission.

Compatibility being validated

iPhone and iPad device builds, signature/export and basic processor tests have been completed. Specific iOS DAW-host compatibility, sustained audio performance, latency, physical audio routing and Apple Vision Pro support have not been certified yet. Do not assume a DAW is supported unless we publish a tested compatibility result.

Report a problem by email

Write to hello@unfire.technology with the app version, device, operating-system version, audio host (if any), sample rate, what happened and reproduction steps. Please do not attach unreleased music or recordings unless specifically agreed in writing.

Purchase information

The desktop ARCHER release for macOS and this separate iOS development product have different identifiers. No iOS sale or App Store availability is being claimed here. Visit the Unfire website for verified announcements.
