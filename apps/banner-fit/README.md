# Banner Fit — Browser Lab (Unfire)

**Status:** independent experimental web utility. Not a native Swift port, a full UnfireSuite release or official format validation.

Features: PNG/JPEG/WebP input up to 20 MiB and 24 million source pixels; six presets plus custom sizes (64–8192 px; max 16 million output pixels); crop/contain, adjustable focal alignment, background fill, PNG/JPEG export.

Privacy: processing is on-device with Canvas. The CSP blocks network connections from this editor. No image uploads, accounts, analytics, third-party fonts or paid services. The original source image is not modified.

Before publishing: run the included tests; verify PNG/JPEG/WebP round trips, dimensions, Safari and mobile export, Chrome and Firefox, accessibility, responsive layout, legal copy, performance, and noindex/SEO. Presets are convenience templates; current target-platform requirements may change. No native app equivalence is claimed.
