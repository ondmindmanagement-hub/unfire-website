Bolt Mobile — Support

Last updated: 13 October 2026 · English

Bolt Mobile is currently an experimental iOS/iPadOS development build, version 0.2.0. It is not yet available as a public App Store release.

Current capabilities

  • Import a user-selected UTF-8 text file of up to 128 KB.
  • Review a proposed separate text copy and approve its export manually.
  • Inspect and decide fictional demonstration requests with an explanation.
  • Use adaptive layouts on supported iPhone and iPad screen sizes.

Important limits

No pairing with the macOS Bolt application, real business systems, unattended agents, production approvals or live external actions is included in this version. Future iPhone Duo and Apple Watch optimizations require additional validation. The product is not certified for business-critical use.

Report a problem by email

Send a written report to hello@unfire.technology, including app version, device model, system version, expected result and steps to reproduce. Do not send confidential documents, personal identifiers, passwords, access keys or customer data.
