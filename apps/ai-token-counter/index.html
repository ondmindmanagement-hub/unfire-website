Accuracy and privacy

This tool estimates tokens with a character-based heuristic; it does not implement OpenAI, Anthropic, Gemini or other provider-specific tokenizers. Exact counts, when provided, override the estimate but are not independently verified. The page uses local browser computations and does not transmit pasted text.
