What this does and does not demonstrate

Demonstrates: repeatable rules for detecting a few severity cues, default-denying unknown actions, blocking refund/data-export requests and requiring explicit review for any record update. Each outcome has a traceable explanation.

Does not demonstrate: model-based natural-language comprehension, reliable incident prioritization in the field, real human approval, production integration, security certification, business value or suitability for a particular buyer.

Tested offline: the eight built-in scenarios and an unknown-action check passed developer assertions at publication. These are only controlled software assertions, not an external audit. View the evaluator source.
