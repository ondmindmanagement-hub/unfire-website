Designed to keep you involved

A review step between the instruction and the action.

Choose a folder and describe a task. Bolt coordinates a proposal, checks its boundaries and lets you inspect the suggested changes. It does not replace your judgment or promise that AI-generated code is correct.

  1. 01 / SCOPEChoose a local folder and the intended task
  2. 02 / BUILDPropose candidate changes using the chosen model
  3. 03 / CHECKApply local permission and boundary checks
  4. 04 / REVIEWAudit the proposal in a separate model step
  5. 05 / APPROVEDecide whether any proposed edit should proceed
Bolt is software to support reviewed AI workflows, not an independently certified security product. No automated check can eliminate all mistakes or risks. Confirm each proposed change, back up valuable files and avoid testing unfamiliar workflows on irreplaceable projects.

Before purchasing

Common questions.

Is Bolt a subscription?

The macOS app is sold through the Mac App Store at the price Apple displays for your region. If you choose live AI mode, provider API usage can incur separate charges from OpenAI or Anthropic under your own provider account.

Does Bolt edit my files without review?

The app is designed to show proposed file changes and request your approval before applying them. Treat the permission checks as safeguards, not a guarantee. Inspect the final scope of every edit yourself.

Can I use Bolt without paying for AI API calls?

You can explore the local simulated test mode without API keys. Live model-generated content requires your own supported provider credentials and may incur usage costs.

What does Bolt require?

A compatible Mac with macOS 14 or later. For live provider mode, you need your own OpenAI and/or Anthropic API access. Check the Mac App Store listing for the latest compatibility and price.

Is the Mac App Store app the same as a custom enterprise pilot?

No. The retail app is a general macOS product. A proposed business feasibility study is a separate, scoped engagement, subject to written agreement, contractual eligibility and technical validation.
