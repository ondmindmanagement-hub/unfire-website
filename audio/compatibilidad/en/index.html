You will be able to purchase Unfire Audio effects directly from our website without buying through another marketplace. Mac and Windows installers are in preparation and testing. Payments are not being accepted, and no commercial licenses or installers are being delivered yet.

In technical preparation

macOS

Internal builds for Apple Silicon (arm64) currently exist as AU, VST3 and standalone apps. Developer ID signing, Apple's notarization service and DAW compatibility testing must be completed before sales begin.

Intel-based Macs are not currently confirmed as supported.

Building and testing

Windows

The cross-platform source code is available. Native Windows x64 builds are being prepared using JUCE as VST3 plugins and standalone applications. The Windows build and tests must pass before downloads are offered.

Windows uses VST3; Apple's Audio Unit (AU) format is not supported on Windows.

How shopping at Unfire will work

1 · Select an effect or bundle

Before payment, each product listing will show the applicable final price, system requirements and supported platforms.

2 · Pay securely

We plan to process website payments through Stripe. Live transactions remain disabled until the payment account and software packages are approved.

3 · Download the right installer

After a confirmed payment, a private delivery system will provide access to compatible downloadable installers. This delivery service is still being tested.

No commercial installers are available in this store yet. The license agreement, applicable taxes, refund terms and statutory digital-content withdrawal information will be finalized before launch. This page provides current development status; it is not a binding sale offer.
