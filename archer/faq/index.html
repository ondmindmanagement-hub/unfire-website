Unfire / Archer / Buyer help

Answers before and after you buy.

Simple help for the Mac App Store version of ARCHER and its AUv3 Audio Unit effect. ARCHER is a clipping tool designed around Gain, Threshold and Atmosphere.

View ARCHER on the Mac App Store Logic Pro workflow guide

What am I purchasing?

The public Mac App Store edition is a macOS app with an AUv3 Audio Unit effect extension. Check the current and promotional prices directly on the Mac App Store; Apple determines regional prices and storefront availability. ARCHER is offered as a one-time paid app, not a subscription.

How do I find ARCHER in Logic Pro?

  1. Install ARCHER from the Mac App Store. Open the app once if macOS requests it.
  2. Launch Logic Pro, select an audio track and choose an Audio FX insert.
  3. Look under Audio Units for Archer.
  4. If it does not appear, quit/reopen Logic Pro and use Logic Pro's Plug-in Manager to locate or rescan Audio Units.

See the official Apple Audio Units guide. Host behavior may vary by Logic Pro and macOS version.

Does the Mac App Store download include VST3 or AUv2?

No. The Mac App Store package is the standalone macOS app with an embedded AUv3 extension. The separate VST3/AUv2 direct-distribution build is not included in that purchase; do not assume it is a free additional download or a supported store entitlement.

Can I use ARCHER on Windows or an iPhone?

The current product listing is for macOS (macOS 12 or later per the store listing). This page does not advertise a Windows or iPhone edition.

Can I hear how it sounds before buying?

Yes. The official Mac App Store listing contains a product video with an audio demonstration. No separate demo executable is required to listen.

Where can I ask for technical help?

Email hello@unfire.technology with the macOS version, Logic Pro version (if relevant), a description of the problem and the exact error text. Do not send passwords, full license keys, purchase-account credentials or private session files.

Is the Logic Pro compatibility guaranteed on every system?

No. The Mac App Store AUv3 extension has passed macOS Audio Unit validation in local development checks, but different host versions, system permissions and installations can behave differently. Check Apple's instructions and contact us with reproducible details if a host cannot load the effect.
