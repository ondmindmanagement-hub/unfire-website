AUv3 on macOS — what to know

The Mac App Store edition of ARCHER includes an AUv3 Audio Unit effect extension, registered under UNFAIR: ARCHER. Apple's Logic Pro documentation explains how Audio Unit extensions are installed and managed in Logic Pro. Host recognition can vary by operating-system and DAW version; check the plug-in manager if the effect does not appear.

Finding an Audio Unit effect in Logic Pro

  1. Install ARCHER from the Mac App Store and open the app once if needed.
  2. In Logic Pro, select an audio channel and open an Audio FX insert.
  3. Look under Audio Units for UNFAIR: ARCHER. If it is missing, open Logic Pro's Plug-in Manager to rescan Audio Units.
  4. Check your Logic Pro version and contact the developer if the Audio Unit does not load.

Apple's official Audio Units guide for Logic Pro provides host installation and troubleshooting instructions. Logic Pro is a trademark of Apple Inc.; ARCHER is independent software, not affiliated with or endorsed by Apple.
