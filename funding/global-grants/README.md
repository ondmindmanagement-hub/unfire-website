# Unfire Global Grants

## Objective

Build a worldwide grant pipeline for Unfire and its product portfolio.

## Zero-financial-risk filter

A grant moves to APPLY NOW only when it is:

- non-repayable when conditions are fulfilled
- up to 100% funded
- no mandatory matching contribution
- no equity
- no loan or repayable advance
- no personal or corporate guarantee
- no mandatory royalties
- no mandatory own contribution
- no material upfront cash requirement from Unfire
- legally accessible directly or through a genuine eligible partner/entity

Normal clawback for fraud, ineligible expenditure or material breach is not treated as ordinary financial risk.

## Status folders

00-database     = master worldwide database
01-apply-now    = verified and actionable
02-conditional  = good but requires a real condition to be solved
03-watch        = future/reopening opportunities
04-excluded     = failed the Unfire filter
05-evidence     = corporate and technical evidence
06-submitted    = applications already submitted
