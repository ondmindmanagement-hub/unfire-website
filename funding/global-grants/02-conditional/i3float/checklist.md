# Final Submission Checklist

## Official call
- [ ] Official source re-opened on submission day
- [ ] Call still open
- [ ] Exact deadline and timezone checked
- [ ] Funding rate checked
- [ ] Payment schedule checked
- [ ] Eligible-cost rules checked
- [ ] Applicant eligibility checked

## Applicant
- [ ] Legal name
- [ ] Address
- [ ] Registration
- [ ] Tax/VAT data
- [ ] SME declaration
- [ ] Bank data if required
- [ ] Financial-capacity documents

## Proposal
- [ ] Application final
- [ ] Work packages final
- [ ] Milestones final
- [ ] Budget final
- [ ] TRL evidence
- [ ] Technical evidence
- [ ] Team CVs
- [ ] Risk table
- [ ] IP/open-source section
- [ ] Impact section
- [ ] Exploitation plan

## Partners
- [ ] Real partner confirmed if required
- [ ] Roles agreed
- [ ] Letters signed
- [ ] No invented entity or office

## Risk controls
- [ ] No mandatory matching
- [ ] No equity
- [ ] No loan
- [ ] No guarantee
- [ ] No royalties
- [ ] No material own-cash exposure
- [ ] No double funding

## Submission
- [ ] Portal account works
- [ ] All PDFs/files upload correctly
- [ ] Final application reviewed manually
- [ ] Submission receipt saved
