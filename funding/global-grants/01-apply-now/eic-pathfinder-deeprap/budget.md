# Budget strategy

The project budget must be derived from:

1. real work packages;
2. real personnel needs;
3. actual project duration;
4. eligible equipment and infrastructure;
5. external expertise where necessary;
6. dissemination and validation costs.

The objective is NOT to request the maximum amount automatically.

The objective is to request the amount that can be credibly justified.

# Double-funding control

Costs funded through EIC Pathfinder cannot also be charged to:

- NLnet;
- NACHIP;
- I3FLOAT;
- Innowwide;
- another Horizon project;
- another public subsidy.

Each cost and deliverable must have a single funding source.
