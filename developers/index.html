Runnable example

Approval gate for synthetic actions.

A minimal, dependency-free JavaScript module illustrates deterministic allow, review and deny decisions, followed by a simple local audit record. It does not execute an external action or connect to an AI model.

import { evaluateAction, appendRecord } from "./approval-gate.mjs";

const action = { id: "demo-1", kind: "simulate", scope: "synthetic" };
const decision = evaluateAction(action);
console.log(decision.status); // "review"

const approved = evaluateAction(action, ["demo-1"]);
console.log(approved.status); // "allow"
const ledger = appendRecord([], action, approved);
console.log(ledger.length); // 1

Run locally: Node.js 18+ · node --test approval-gate.test.mjs. Download only the publicly visible reference files; this example requires no API key or network access.

What this demonstrates

Conservative defaults, explicit consent for synthetic simulations, predictable decision reasons and immutable append-only-in-memory records.
