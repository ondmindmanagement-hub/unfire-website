Teacher handout · 01

Make, listen, export.

  1. Prepare · 5 minutes

    Check device compatibility and institutional policy. Open Portable Synth on Android, or use an existing DAW as an alternative.

  2. Explore timbre · 5–10 minutes

    Choose an available sound engine. Compare two filter settings and describe the audible difference.

  3. Compose · 10 minutes

    Create an original four-bar rhythm or melody. Experiment with variation, dynamics and silence. Use original or properly cleared sounds.

  4. Export · 5–10 minutes

    Export WAV audio using the installed app's available tools. Import it as an audio clip into an existing desktop DAW. If export is unavailable, use an existing original WAV.

  5. Reflect · 5 minutes

    Compare the mobile and desktop workflow. Explain how rendered audio differs from editable MIDI or native project interchange.

For educators

Learning outcomes

  • Recognize changes in synthesis by ear.
  • Build a coherent short musical pattern.
  • Understand WAV export and audio interchange.
  • Explain workflow limitations.

Suggested assessment

  • Originality: 25%
  • Musical structure: 25%
  • Synthesis understanding: 25%
  • Workflow explanation: 25%
