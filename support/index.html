Product support

Help with Unfire applications, installation and common issues. Support is available by email.

Archer

For installation, plug-in recognition or audio processing questions, include your operating system, Archer version, host application and the steps that reproduce the issue.

  • For the Audio Unit extension on iPhone or iPad, install Archer, then close and reopen the compatible audio host before checking its Audio Units list.
  • If a host still does not recognize the plug-in, mention the host name and version when contacting support.
  • For sound issues, include the audio sample rate and whether the issue occurs in standalone mode or inside a host.

Pocket Capture

Pocket Capture is a local audio recording and WAV-editing application undergoing testing.

  • To record, allow microphone access when iOS requests it. You can review this permission under Settings → Privacy & Security → Microphone.
  • Use the sample editor to adjust the trim range and export WAV. You can then share the exported file through the iOS share sheet.
  • If export fails, include your iOS version, input file format and approximate file length when contacting support. Do not email private recordings unless you choose to share them.

Privacy and personal data

Read the Unfire privacy policy. Please do not send passwords, authentication codes or confidential recordings to support.

Contact support

Email hello@unfire.technology with the product name, version, device and a brief description of the issue. We handle support requests by email.
