Qué debes saber

Para conectarse, los participantes necesitan internet y una sala activa. Algunas redes, navegadores o desconexiones del anfitrión pueden impedir o interrumpir una partida.

Estado: multijugador en validación. Aún faltan pruebas completas de reconexión y dispositivos físicos.

DESKTOP / INSTALL

Juega desde tu ordenador.

Puedes abrir el juego gratuitamente desde Windows, macOS o Linux en un navegador compatible. Si tu navegador ofrece la instalación de sitios como aplicación, podrás tener un acceso directo independiente.

Instalación de la versión web

  1. Abre el juego desde Chrome, Edge o un navegador compatible.
  2. Busca la opción de instalación del navegador, si aparece. En Safari para macOS, comprueba la opción Añadir al Dock.
  3. Abre el acceso creado para volver al juego cuando quieras.

Descargas nativas

Las compilaciones de escritorio con instaladores para macOS y Windows todavía no están publicadas ni verificadas. No ofrecemos archivos .dmg o .exe falsos.

La instalación web no significa que el juego funcione sin conexión. Para jugar online siempre necesitarás internet.
