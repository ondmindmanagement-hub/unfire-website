DESKTOP / INSTALL

Juega desde tu ordenador.

Puedes abrir el juego gratuitamente desde Windows, macOS o Linux en un navegador compatible. Si tu navegador ofrece la instalación de sitios como aplicación, podrás tener un acceso directo independiente.

Instalación de la versión web

  1. Abre el juego desde Chrome, Edge o un navegador compatible.
  2. Busca la opción de instalación del navegador, si aparece. En Safari para macOS, comprueba la opción Añadir al Dock.
  3. Abre el acceso creado para volver al juego cuando quieras.
