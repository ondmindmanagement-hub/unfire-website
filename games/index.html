DESKTOP / INSTALL

Play on your computer.

You can open the game for free on Windows, macOS or Linux in a compatible browser. If your browser offers website installation as an app, you can add a standalone shortcut.

Install the web version

  1. Open the game in Chrome, Edge or another compatible browser.
  2. Look for an install option in your browser, if offered. In Safari for macOS, check the Add to Dock option.
  3. Launch the new shortcut to return to the game whenever you want.
