02 / Reproducibility

Inspect the test.
Run it yourself.

The checker uses only Python's standard library, performs read-only HTTPS requests against nine predetermined Unfire pages and prints structured JSON. No login, tracking identifier, customer data or paid service is required.

01 / FETCH

Public GET

Request a fixed allowlist of own-site routes, with a finite network timeout.

02 / PARSE

HTML basics

Check status, media type, title, one H1, responsive viewport metadata and canonical URL presence.

03 / REPORT

Explicit failures

Emit JSON with per-route observations and exit with an error if any check fails.

python3 check.py
# Outputs: total, passed, and per-route JSON details.
# Exits 0 on pass; exits 1 if a selected check fails.
